# workflows — Repeatable Procedures

Step-by-step procedures for common multi-file tasks. Each one exists to keep the
whole monorepo consistent — the envelope, the zod boundaries, the token layer,
the translated strings — when many agents touch the codebase in parallel. Every
procedure is derived from a real shipped example, named at the top of the file so
you can go read the code it came from.

| File                                                         | Use when you're…                                                                     | Key output                                                                                                                                                                                                                                                                               |
| ------------------------------------------------------------ | ------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [add-api-endpoint.md](./add-api-endpoint.md)                 | Adding or changing a REST endpoint. Modelled on the `labels.*` quartet.              | Shared zod schema → validation file → thin route with guards → controller (`getParsed`, `respond`) → service (`withTx` + the activity row inside it, telemetry and the domain event after it) → mount → supertest role matrix → web hook + query key.                                    |
| [add-view.md](./add-view.md)                                 | Adding a page or a major view to the web app. Modelled on the Calendar.              | Lazy route with `taskSheetRoute()`, sidebar **and** palette entries, data hook + query key, pure `kebab-case.ts` logic modules, en+ar namespace, all four render states, RTL pass, colocated tests.                                                                                      |
| [db-migration.md](./db-migration.md)                         | Changing the Postgres schema, adding an index, or widening a pg enum.                | Drizzle schema edit → `db:generate` → SQL read and hand-edited only for what drizzle cannot emit → `db:reset && db:seed` from empty → shared schemas, `schema.test.ts` and `database.md` updated.                                                                                        |
| [add-translated-string.md](./add-translated-string.md)       | Adding or changing any user-facing copy — including a new locale namespace.          | English key (the shape authority) + Arabic twin with the full six-category plural set where it pluralizes, `useTranslation` call, `lib/format.ts` for numbers/dates, `locales.test.ts` green, RTL checked.                                                                               |
| [add-socket-event.md](./add-socket-event.md)                 | Making a mutation reach other people's open tabs.                                    | `scope:verb` in the shared event map, service publishes a domain event, bridge hydrates → **parses** → `io.to(room).except(originSocketId)`, `realtime-cache.ts` patches one named key, `useRealtime` subscription, both-sides tests.                                                    |
| [add-notification-trigger.md](./add-notification-trigger.md) | Making the bell light up for a new reason.                                           | Type in the shared enum **and** the pg enum, audience minus actor/muted/non-member, denormalized payload snapshot, bootstrap subscription, `notification:new` to `user:{id}`, sentence in en **and** ar, payload-only click target.                                                      |
| [add-analytics-metric.md](./add-analytics-metric.md)         | Adding a number to the `/admin/analytics` console. Modelled on `engagement.signups`. | Domain payload field (or a reuse) → the aggregate in SQL **inside the existing round trip** → en + ar catalog keys → a `defineMetric` entry reading `loadDomain.<domain>` → tile/card linked with `detailPath` → the registry's i18n-exhaustiveness test. **No new route, no new page.** |
